# Year 1 Science – Everyday Materials Adventure

An interactive, game-based science lesson for children aged 6–7 (Year 1), built from the *Y1 Everyday Materials Home Learning Booklet*.

**To use:** open `everyday_materials_year1.html` in any modern browser. You don't need to install anything, and it works offline.

## What's inside (27 screens)

| Part | Content |
|---|---|
| 1 · The Big Discovery | Object vs material, flip cards, a chair made from several materials, a checkpoint |
| 2 · Material Explorer | Wood, plastic, metal, glass, fabric and rock/stone: where each comes from, examples, properties, fun facts, matching each material to its source |
| 3 · Property Detective | Hard, soft, waterproof, absorbent, flexible/stretchy, transparent and opaque, each with an animated experiment. Also opposites (shiny/dull, smooth/rough, rigid) and a comparison board |
| 4 · Science Games | A) Object/material sorting (drag or tap) · B) Mystery feely bag (10 clue puzzles) · C) House hunt checklist · D) Property matching + tick table · Bonus: umbrella experiment (enquiry skills) |
| 5 · Science Challenge | 16-question quiz with feedback, a score, achievement levels and *Review my mistakes* |
| Certificate | A printable Little Science Explorer certificate with badges |

Also included: stars, 6 badges, a progress bar, a hidden **Teacher's Help** panel on every screen, read-aloud (🔊 / 🗣️), sound effects, and saved progress (localStorage). It works on phones, tablets and desktops.

## External assets

None are needed. All pictures are inline SVG or CSS drawings.

- *Optional:* the Google Font **Fredoka**. If you're offline, the page falls back to system fonts.
- *Optional:* the YouTube "Watch & Learn" links from the booklet, listed in Teacher's Help on the certificate screen.
